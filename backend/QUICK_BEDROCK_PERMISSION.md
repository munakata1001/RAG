# Bedrock権限の付与方法（簡易版）

「Bedrock権限が見つかりません」というメッセージが表示された場合の対処法です。

## 手順

### ステップ1: AWSコンソールでIAMを開く

1. AWSコンソールにログイン
2. 検索バーに「IAM」と入力
3. 「IAM」サービスを選択

### ステップ2: ユーザーを選択

1. 左メニューから「ユーザー」をクリック
2. Bedrockを使用するIAMユーザーを選択（ユーザー名をクリック）

### ステップ3: 権限を追加

1. 「許可」タブをクリック
2. 「許可を追加」ボタンをクリック
3. 「ポリシーを直接アタッチ」を選択
4. 検索バーに「Bedrock」と入力
5. **`AmazonBedrockFullAccess`** にチェックを入れる
6. 「次へ」をクリック
7. 「許可を追加」をクリック

### ステップ4: 確認

1. ユーザー詳細ページの「許可」タブで確認
2. `AmazonBedrockFullAccess`が表示されていれば成功

## 完了後の確認

権限を付与した後、以下で確認できます：

```bash
cd C:\Users\munak\Desktop\RAG研修\backend
python verify_aws_credentials.py
```

「✓ Bedrock権限が確認されました」と表示されれば成功です。

## トラブルシューティング

### ポリシーが見つからない場合

1. 検索バーに「Bedrock」と入力
2. フィルターで「AWS管理」を選択
3. スクロールして`AmazonBedrockFullAccess`を探す

### 権限を追加できない場合

- 管理者権限が必要です
- 管理者アカウントでログインしてください
